# Assets and rendering references

- Photographic grass, concrete, asphalt, plaster, brick, bark and leaves: [ambientCG](https://ambientcg.com/) — CC0. Assets: Grass001, Concrete034, Asphalt012, Plaster001, Bricks059, Bark008, LeafSet001.
- Sky: [Poly Haven kloofendal_48d_partly_cloudy](https://polyhaven.com/a/kloofendal_48d_partly_cloudy) — CC0.
- Tree trunk/branches: [Poly Haven tree_small_02](https://polyhaven.com/a/tree_small_02) — CC0. Game foliage uses complete photographed leaf cards from LeafSet001; distant LOD retains fewer complete cards.
- Soldier: [three.js Soldier.glb](https://github.com/mrdoob/three.js/blob/dev/examples/models/gltf/Soldier.glb). The [upstream skinning example](https://github.com/mrdoob/three.js/blob/r170/examples/webgl_animation_skinning_blending.html) credits [Mixamo](https://www.mixamo.com/); this asset is not labeled CC0.
- Zombie: [YUKA fuzzy-logic example](https://github.com/Mugen87/yuka/tree/master/examples/fuzzy). Upstream example credits the Mixamo character pipeline; upstream model files are retained for local prototyping.
- Rifle: Ptis, [Sci-fi Assault Rifle](https://sketchfab.com/3d-models/sci-fi-assault-rifle-d2596ed504b84ffda761b0886c26b202), CC BY-NC. This build is for noncommercial use; see YUKA-model-credits.txt.
- Shotgun: Harry_L, [Shotgun](https://sketchfab.com/models/53b158b0d5a54b4491b09d1fb3058e29), CC BY. See shotgun-credits.txt.
- Pistol: Feche Pedroza, [SciFi Gun](https://sketchfab.com/models/04a9f3ccb5b14dc38a28b27c1916e18e), CC BY. See pistol-credits.txt.
- Audio: preserved from [YUKA shooter example](https://github.com/Mugen87/yuka/tree/master/examples/playground/shooter/audio). The upstream audio directory has no separate attribution document; YUKA MIT license is retained.
- AI navigation: [Mugen87/YUKA](https://github.com/Mugen87/yuka), MIT. Soldier AI uses A* routes, steering/separation and visibility checks; zombies use direct pursuit and local obstacle feelers.
- Rendering implementation: [three.js r170 GTAO example](https://github.com/mrdoob/three.js/blob/r170/examples/webgl_postprocessing_gtao.html), [AgX implementation](https://github.com/mrdoob/three.js/blob/r170/src/renderers/shaders/ShaderChunk/tonemapping_pars_fragment.glsl.js), [SMAA](https://github.com/mrdoob/three.js/blob/r170/examples/jsm/postprocessing/SMAAPass.js). Three.js MIT license is included with the dependency.
- Additional rendering research: [0beqz/realism-effects](https://github.com/0beqz/realism-effects). Reviewed its SSGI/AO/temporal anti-aliasing approach; this build uses Three.js's GTAO and SMAA passes and does not include the realism-effects library.
- Motion library `anim-library.glb` (46 clips: Idle/Walk/Jog/Sprint/Crouch/Death01/Hit_*/Pistol_*): [Quaternius Universal Animation Library](https://quaternius.com/). Licenced under the **Quaternius Asset License v1.0** — free for personal, educational and commercial games, no credit required, but the assets themselves may not be resold or redistributed as an asset pack.
- Character avatars in `avatars/`: licences verified file by file. **CC0**: `orion.glb`, and the VRoid Hub models Vita/Vivi/Victoria_Rubin/Sakurada_Fumiriya/Sendagaya_Shibu/Sendagaya_Shino/Darkness_Shibu; HairSample_Male/Female are named in pixiv's CC0 section. **Disputed**: the VRoid *Base models* (fem/masc) are listed as CC0 by pixiv but carry `licenseName=Other` inside the file. **Not CC0**: AvatarSample_A/B/C (`sample-a.glb`, `anime-b.glb`, `anime-c.glb`) fall under pixiv's "Models with particular conditions of use" — the dedicated terms article could not be read, so treat them as restricted. **Unconfirmed / no licence**: `anime-alicia.glb` (UniVRM test model), `anime-naruto.glb` and `anime-chiikawa.glb` (fan models in repositories with no LICENSE file; character copyright remains with the original rights holders). `anime-sample1.glb` (VRM 1.0 Constraint Sample) is under the **VRM Public License 1.0**.
  The per-file table, the exact quoted wording and every rejected candidate are recorded in `work/avatar-hunt-report.md`. **Unconfirmed entries are for local demonstration only and must not be redistributed.**
- Avatar preparation: `work/optimize_avatars.py` clears shape keys, joins meshes, decimates to about 4500 triangles and caps textures at 384px. Animation is retargeted at runtime by `bakeRetarget` in `web/shooter/client.js`.

The campus geometry is procedural and remains an approximation of the provided photographs. It is not a photogrammetric scan. The game supports rendering controls; the native Blender model contains packed photographic textures and linked real trees, but the game's screen-space postprocessing is applied by the browser.
